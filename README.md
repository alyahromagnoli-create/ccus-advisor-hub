# 碳研导航：CCUS 导师筛选

## 数据边界

- 页面仅展示已整理的公开字段和官方来源链接。
- “待核验”表示尚未完成人工复核，不代表招生资格或论文指标已经确认。
- 浏览器中的收藏、联系状态和备注只保存在访问者自己的浏览器，不上传到服务器。
- 导师职称、研究方向、招生状态和代表论文可能随官网更新，请以链接中的学校或研究所官方页面为准。
- 自动新增论文来自 OpenAlex 的作者—机构—主题联合匹配，页面同时提供 DOI 与 OpenAlex 记录链接；OpenAlex 两年平均被引次数明确标注为“非 JIF”。
- Clarivate JCR 影响因子属于授权数据；没有明确年份、来源和授权依据的记录不会填入 JIF 数值。

本仓库是公开部署快照，不包含采集脚本、原始抓取资料、审核队列或本地工作记录。
